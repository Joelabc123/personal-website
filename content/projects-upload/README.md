# Projektbilder-Upload

Lege hier neue, noch nicht eingebundene Originalbilder für die Projekte ab.

Dieser Ordner wird von der Projektübersicht noch nicht verarbeitet. Die Bilder
können später anhand eines Prompts geprüft, dem passenden Projekt aus
`lib/projects.ts` zugeordnet, für die Website aufbereitet und anstelle der
Platzhalter eingebunden werden.

Benutze möglichst aussagekräftige Dateinamen, die das Projekt und das Motiv
erkennen lassen, zum Beispiel:

```text
property-management-dashboard.png
red-black-tree-editor.jpg
quiz-duel-game-screen.webp
online-board-game-lobby.png
finance-platform-overview.jpg
```

Die Originalbilder in diesem Ordner werden von Git ignoriert.
