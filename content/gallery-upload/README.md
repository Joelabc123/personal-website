# Galerie-Upload

Lege hier neue, noch unsortierte Originalbilder ab.

Dieser Ordner wird von der Galerie noch nicht verarbeitet. Die Bilder können
später anhand eines Prompts geprüft, in
`content/gallery/<jahr>/<land>/<reise>/` einsortiert und mit einer passenden
`_meta.json` in die Galerie aufgenommen werden.

Die Originalbilder in diesem Ordner werden von Git ignoriert.
